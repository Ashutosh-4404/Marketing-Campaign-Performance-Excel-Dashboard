# Marketing Campaign Performance Analysis – Excel Dashboard

## Project Overview
This project analyzes marketing campaign performance across different channels and regions using Microsoft Excel.

## Business Objective
- Analyze marketing campaign performance.
- Measure profitability and advertising efficiency.
- Compare campaign performance across channels and regions.
- Build an interactive Excel dashboard.

## Dataset
The dataset contains 500 marketing campaign records.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas

## Data Cleaning and Transformation
- Removed duplicate records.
- Checked missing values.
- Corrected data formatting.
- Created calculated columns:
  - CTR
  - CPC
  - CPA
  - ROAS
  - Profit
  - Profit Margin %

## Dashboard Features
- Revenue vs Spend Trend
- Channel-wise ROAS
- Region-wise Conversions
- Budget Allocation by Channel
- Impressions, Clicks and Conversions
- Interactive Slicers
